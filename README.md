# Spring-Mixin Template

A minimal Spring Boot project showcasing integration with [SpongePowered Mixin](https://github.com/SpongePowered/Mixin) via the [`net.lenni0451.classtransform`](https://github.com/Lenni0451/Classtransform) library. Use this template to quickly bootstrap applications where you need to apply runtime bytecode transformations alongside Spring’s powerful ecosystem.
